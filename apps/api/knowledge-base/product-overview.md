# QUORUM product overview

Source: README.md

QUORUM is an autonomous browser agent for accounting and finance professionals. A user
states a goal in plain English. The system plans work, browses allowed websites, extracts
claims, verifies them, and returns results with traceable evidence.

The product is designed around three principles:

- Claims, not unsupported answers: extracted values retain their source URL and quoted
  text, with confidence and model provenance.
- Human control: risky browser actions require approval before execution.
- Recovery: failures follow explicit recovery strategies and can hand control to a person.

QUORUM is not a medical assistant and its documentation does not provide health advice.
